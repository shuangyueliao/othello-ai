# Othello Pro · Reversi vs AI

Free single-file HTML5 board game. Classic Othello (Reversi) against a
tunable AI — three difficulty levels (Easy / Normal / Hard), with Hard
running iterative-deepening minimax (2-4 ply, position weights + mobility,
sub-second moves). Ripple disc-flip animations, legal-move hints, last-move
marker, live disc counts and per-difficulty win/loss/draw records. One HTML
file, zero external assets.

**Play:** https://shuangyueliao.github.io/othello-ai/

- Mouse / touch / arrow keys, procedural WebAudio sounds
- Procedural canvas visuals (ink-green felt, ivory & jet discs), no dependencies
